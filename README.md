# BuildDeck

Android project dashboard and AI Control Center, Batch 2 (`v0.2.0`).

This repository is being initialized from the packaged Android source. The temporary `builddeck-source.tar.xz.b64` archive will be unpacked by the bootstrap workflow into the project files. The Android debug APK is produced by GitHub Actions, and source changes require user approval within BuildDeck.

**Note:** This application is experimental and has not yet passed a full Android build or device test. Do not commit private tokens or signing keys.
